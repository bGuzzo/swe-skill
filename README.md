# swe-skill

**SWE skill** (Agent Skills compliant) is an AI skill to follow my favorite code style and enforce my experience.

## Features
* Defines 26 core principles to enforce across all sessions.
* Spring Boot and OOP-oriented.
* Python and PyTorch-specific.
* Enforces SOLID principles.
* Enforces the 23 classic **Design Patterns**.
* Enforces core **Clean Code** principles.
* Requires ASD-STE100 for all text that the agent writes. Read [LANGUAGE.md](./references/LANGUAGE.md).
* Includes an [ASD-STE100 guide](./assets/ASD_STE100.md) with official sources and review checks.

## Open Standards
* Follows the **Agent Skills** specification.
* Compatible with major harnesses like AGY, Claude Code, etc.
